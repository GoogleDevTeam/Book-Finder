# Book-Finder

**Repository status:** Planning draft — not approved for implementation  
**Visibility:** Private

Book-Finder is a proposed Android APK app for identifying several books from a photo of a book list and finding physical-book and ebook options with clear Saudi Arabia delivery and region status.

## Scope lock

This repository is the single source of truth for product scope. The current plan is still in discovery. Nothing is authorized for implementation until the owner explicitly approves the plan and says to begin implementation.

Only requirements marked **Confirmed** in the plan may be treated as agreed. Open questions and recommendations are not approvals. Do not add features, providers, data collection, integrations, or app behavior that is not in the approved plan. Put new ideas in a change proposal and wait for explicit approval before changing scope or implementing them.

## Working rules

1. Read the approved plan before doing product or engineering work.
2. If a request conflicts with the plan, stop and ask whether to revise the plan; do not silently choose.
3. Keep provider examples distinct from confirmed integrations.
4. Never describe uncertain Saudi shipping or ebook-region access as confirmed.
5. Keep secrets out of GitHub and the APK. Private repository access is not a secrets-management system.

The initial repository intentionally contains planning documents only.
